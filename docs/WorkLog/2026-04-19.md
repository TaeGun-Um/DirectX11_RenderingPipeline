## 5. 디퍼드 알파 패스 정리

### 기존 문제
- `AlphaRenderTarget`에 depth 미첨부 → 반투명이 불투명 지오메트리 뒤에서도 앞에 그려짐
- `StaticAlpha` 머티리얼이 `EngineDepth`(쓰기 ON) 사용 → 알파 간 상호 간섭
- 별도 RT에 그린 뒤 `AlphaMerge` → **SRC_ALPHA 곱이 두 번 적용되는 더블 블렌드**
- Merge 단계 머티리얼(`DeferredMerge`/`RenderTargetMerge`/`AlphaMerge`)들이 `AlwayDepth`(쓰기 ON) 사용 → 합성 풀스크린 쿼드가 **opaque depth를 전부 덮어씀** (핵심 버그)

### 해결
1. **신규 `AlphaDepth` state**: `DepthEnable=true, WriteMask=ZERO, Func=LESS_EQUAL`
2. **신규 `MergeDepth` state**: `DepthEnable=false, StencilEnable=false` — 합성 쿼드가 depth 를 건드리지 않게
3. `StaticAlpha` → `AlphaDepth`
4. `DeferredMerge` / `RenderTargetMerge` / `AlphaMerge` → `MergeDepth`
5. `Ext_DirectXRenderTarget::RenderTargetColorClear()` 신설 (RTV만 클리어, DSV 보존)
6. `Ext_Camera::Rendering` 재구성
   - 메인 패스: 알파 유닛 **스킵** (opaque만 G-Buffer에)
   - 합성 직전: `RenderTargetColorClear()` 로 color만 클리어 → opaque depth 유지
   - 합성 (SkyBox + LightMerge) 수행
   - **Forward 알파 패스**: 합성 완료된 `CameraRenderTarget` 에 직접 그림 (back-to-front 정렬, 공유 depth 테스트)
   - 기존 `AlphaMerge(AlphaRenderTarget)` 호출 제거

### 결과
- 반투명 오브젝트가 공유 depth 로 정확히 occluded
- SRC_ALPHA 블렌드 한 번만 적용 → 의도한 50% 투명도 정상
- 여러 알파끼리도 거리순 블렌딩 깔끔
